# 개인정보 처리 설계 초안 (손님 영역 B)

> **법률 자문이 아니다.** 공개 자료(검색 결과)를 바탕으로 검토할 구조를 정리한 가설이며, 등록 기능을 켜기 전에 변호사 검토가 필요하다. 조문 번호와 현행 내용은 국가법령정보센터 원문으로 다시 확인한다.

## 1. 현재 규칙과의 관계

- [[개발에이전트_작업규약]] §2는 U-23으로 개정됐다: 고객 개인정보는 원칙적으로 수집하지 않고, **손님이 카카오·네이버 계정 연동으로 직접 등록하며 동의할 때만** 저장한다.
- **수집 시점 = 연동 등록 시점 하나.** 꾸미기 중 "다음에도 이 캐릭터로 등장하기"를 누르면 카카오/네이버 로그인 → 동의 화면 → 저장. 연동하지 않으면 그 손님의 개인정보는 저장하지 않는다.
- **연동 시 받는 항목은 최소로:** 제공자 사용자 ID(서비스별 고유값)만 필수. 닉네임·이메일·전화번호는 받지 않는다(필요해지면 항목별 추가 동의). 카카오·네이버 로그인의 앱 검수·비즈니스 인증 조건은 `미검증`.
- **연동 안 한 손님에게 남는 것:** 인원, 연령대, 방문 관계(가족·친구 등), 방문 시각, 캐릭터 외형, 익명 기기 토큰(쿠키).
  - 주의: 익명 기기 토큰으로 같은 폰의 재방문을 이어 붙이면, 다른 정보와 결합해 특정 개인을 알아볼 수 있는지가 쟁점이 될 수 있다. 법률 검토에서 확인하고, 그 전까지는 토큰 보관기간을 짧게 두고 연동 전 재방문 기록을 개인 단위로 쌓지 않는 쪽을 기본값으로 한다.
- 아래 표는 연동 등록 기능을 켜는 시점부터 적용된다.

## 2. 처리위탁과 제3자 제공의 구분 기준

- 누구의 업무와 이익을 위해 개인정보가 넘어가는지, 누구의 관리·감독 아래 처리되는지로 판단한다. 계약서 이름보다 실제 구조가 기준이다.
- **처리위탁(개인정보 보호법 제26조):** 위탁자 업무를 대신 처리. 정보주체 동의는 원칙적으로 필요 없고 위탁 사실 공개, 위탁 계약이 필요하다. 2023년 개정으로 재위탁에는 원래 위탁자 동의가 필요하다.
- **제3자 제공(제17조):** 받는 쪽이 자기 사업에 쓰는 이전. 원칙적으로 정보주체 동의가 필요하다.

## 3. 데이터 흐름별 역할 가설

| 데이터 흐름 | 예상 성격 | 필요한 것 |
|---|---|---|
| 베타: 매장 손님 데이터를 우리 시스템이 저장·관리 | 매장 → 우리 처리위탁 | 매장 처리방침에 위탁 사실 공개, 위탁 계약 |
| 전역 캐릭터·손님 프로필 (매장 무관, 우리 서비스) | 우리가 직접 개인정보처리자 | 우리 이름의 수집·이용 동의, 처리방침 공개 |
| 우리 → 매장으로 고객 목록·연락처 (카카오 고객 관리 연계 포함) | 제3자 제공 가능성 높음 | 매장별로 구분한 제공 동의 |
| 쿠폰·알림 같은 영리 목적 광고 메시지 | 정보통신망법 제50조 우선 적용 | 수신자의 명시적 사전 동의 (원칙) |
| 만 14세 미만 아동 | 개인정보 보호법 제22조의2 | 법정대리인 동의 + 실제 동의 여부 확인 |

## 4. 동의 화면 설계 원칙

- 동의 항목은 각각 나눠서 받는다 (제22조 제1항).
- 선택 동의를 거부했다고 서비스를 거부하지 않는다 (제22조 제5항). 등록 없이도 캐릭터 꾸미기·화면 등장·사진 카드는 된다.
- 동의 종류(초안): ① 플랫폼 캐릭터 유지(전역) ② 매장별 방문 혜택·스탬프 ③ 매장별 광고성 정보 수신 ④ 매장에 고객 정보 제공. `consents` 테이블에 종류·약관 버전·동의·철회 시각을 남긴다.
- 대신 꾸민 일행 캐릭터는 등록자의 "내 일행"으로 외형·연령대만 저장한다. 일행의 연락처 같은 식별 정보는 받지 않는다. 일행 본인의 등록은 본인 기기에서만.
- 매장 TV에는 캐릭터만 띄우고, 손님이 노출을 끌 수 있다.

## 5. 사진 → 캐릭터 (후순위)

얼굴 사진은 개인정보이고, 식별에 쓰면 민감정보(생체인식) 규제까지 갈 수 있다. 하게 되면 폰 안에서만 처리하고 저장·전송하지 않으며, 기존 캐릭터 세트 중 비슷한 것을 고르는 방식으로 한다.

## 6. 남은 확인

- 변호사 검토: 역할 표(§3), 동의 문구, 처리방침, 보유기간.
- 카카오 채널·로그인 API 이용 조건과 비즈니스 인증 (`미검증`).
- 보유기간·파기 정책(제21조), 안전조치(제29조) 구체화.
