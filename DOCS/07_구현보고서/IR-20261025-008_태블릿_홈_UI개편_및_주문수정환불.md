# IR-20261025-008 태블릿 현장 입력 친화형 HOME UI 개편, 연령대 터치 스텝퍼, 영업일 터치 설정 및 주문 수정·환불 구현보고서

## 1. 작업 요약

- **관련 작업지시서:** [[WO-20261025-008_태블릿_홈_UI개편_및_주문수정환불]]
- **배경:** 3회차 사용자 인터뷰([[인터뷰_기록#3회차]], `U-08`~`U-10`)에서 도출된 현장 태블릿 UX 요구사항을 반영하여, 사무용 대시보드 형태였던 `HOME(S02)`과 전체 셸(`App.tsx`)을 **매장 영업 중 터치 입력에 최적화된 구조**로 개편하고, **POS 연동 모드(자동 연동 안내) vs CSV 모드(직접 수정·환불 전환·수동 추가)** 분기형 주문 관리 파이프라인을 추가했다.

---

## 2. 주요 구현 내역

### 2.1 사이드 네비게이션 숨기기/접기 및 상단 KPI 배지 통합 (`frontend/src/app/App.tsx`)
- 영업 중에는 `HOME` 화면에 고정되어 있다가 브레이크 타임·마감 후에만 다른 탭으로 이동하는 매장 동선에 맞춰, 좌측 사이드바를 **기본 숨김(접힘) 상태**로 시작하고 상단 좌측 `☰ 메뉴 · 탭 이동` 버튼으로 언제든 열고 닫을 수 있도록 변경했다.
- 사이드바가 닫혀 있을 때 `HOME` 화면이 태블릿 가로 폭 전체(`max-w-[1600px]`)를 온전히 활용한다.
- 기존 `HOME` 상단에 큰 면적을 차지하던 KPI 카드 3종(`현재 착석 테이블/손님`, `누적 방문 기록`, `수집된 순매출`)을 상단 헤더 우측의 **컴팩트 요약 배지**로 통합했다.

### 2.2 첫 매장 등록(`S00`) 및 설정(`S07`) 영업일·운영시간 터치 UI (`App.tsx`, `SettingsPage.tsx`)
- `화,수,목,금,토,일` 텍스트 직접 타이핑 대신 **`월` `화` `수` `목` `금` `토` `일` 7개 요일 터치 토글 버튼**과 원탭 프리셋(`월요일 휴무`, `매일 영업`, `평일만`)을 적용했다.
- 운영시간(`11:30-22:00`) 또한 오픈/마감 시간 터치 버튼으로 즉시 선택할 수 있게 개편했다.

### 2.3 HOME(`S02`) 현장 입력 친화형 2D 배치 홀 및 연령대 터치 스텝퍼 (`frontend/src/pages/HomePage.tsx`)
- 불필요한 기획 설명 문구(`POS에서 자동 수집되는 메뉴·주문은...`, `화면 S02 · REQ-002...`)와 중복되던 `- 1명 / 현재 선택: N명 / + 1명` 행을 제거했다.
- **좌측 메인 홀 구역(`lg:grid-cols-[1.85fr_1fr]`):** 화면에서 가장 넓은 면적을 차지하며, 출입구·카운터·주방 패스라인과 테이블 상하 좌석 도트가 표현된 2D 매장 홀 캔버스로 구성해 향후 도트 그래픽 스킨 확장에 바로 대응하도록 설계했다.
- **우측 선택 테이블 터치 패널 — 연령대 카운터(`[-] 20대 (N) [+]`):**
  - 드롭다운 대신 `10대`, `20대`, `30대`, `40대`, `50대`, `60대+` 각각에 대해 `[-]` / `[+]` 터치 스텝퍼 버튼을 배치했다.
  - 연령대 스텝퍼의 `+`를 누르면 각 연령대 인원이 올라가면서 **총 방문 인원수(`partySize`)가 자동으로 합산**되며, 연령 구성을 모를 때만 상단 `1명~8명` 빠른 버튼을 터치하도록 연동했다.

### 2.4 주문 수정 · 환불(취소) 대응 상호작용 (`POS 모드 자동 vs CSV 모드 직접 수정 분기`)
- **백엔드 (`backend/app/services/imports.py`, `backend/app/api/v1/endpoints/imports.py`):**
  - `GET /api/v1/stores/{store_id}/sales-orders`: 주문 목록 및 품목 상세, 현재 수집 모드(`pos_mode`), 수동 수정 가능 여부(`can_manual_edit = (pos_mode == "CSV_UPLOAD")`) 반환.
  - `PATCH /api/v1/stores/{store_id}/sales-orders/{order_id}`:
    - `TOSS_OPEN_API` / `TOSS_PLUGIN` 모드에서는 `409 Conflict` (`POS_MODE_MANUAL_EDIT_LOCKED`)로 수동 수정을 차단.
    - `CSV_UPLOAD` 모드에서는 주문의 **`COMPLETED` ↔ `CANCELLED` (환불/취소 전환)** 및 **품목별 수량 증감**을 수행하고, 변경 즉시 예상 재고(`S05` 이론 소모량 복원/차감)와 판매 집계(`S06`)에 반영된다.
  - `POST /api/v1/stores/{store_id}/sales-orders`: `CSV_UPLOAD` 모드에서 현장 주문을 메뉴 선택 + 수량으로 즉시 수동 등록.
- **프론트엔드 (`HomePage.tsx`):**
  - 우측 패널 하단 `🧾 주문 수정 · 환불(취소) 관리` 버튼을 누르면 모달이 열리며, POS 모드일 때는 자동 연동 안내 배너를, CSV 모드일 때는 현장 주문 추가·품목 수량(`-`/`+`) 조절·원탭 `환불 · 주문취소` 전환 UI를 제공한다.
