# IR-20261026-001 — 프론트 화면 디자인 정리 (S00~S07)

## 1. 구현한 화면 / 결정 ID
- 화면 S00~S07 전체 시각 정리. 결정: U-08·U-11 유지, **P-13 신규**(강조색 와인·서체 Pretendard 임시안).
- 스킬 `design-taste-frontend` 앱 화면 런: 스타일 `accent-ladder` (seed 697165525, 서체 유지 재딜 320705487).
  - 재딜 사유: 시트 서체 DM Sans에는 한글 글리프가 없어 Pretendard로 `--keep type`.
  - 셸 구조는 U-08(접이식 사이드바·상단 요약 지표)이 사용자 확정 사항이므로 시트의 Open plane 대신 기존 구조 유지.
  - 얼굴(face): 시트의 raspberry 대신 매장 세계의 와인색 램프 + 바탕을 강조색 쪽으로 기운 `#faf8f9`. 고유 요소: 2D 도트 홀(U-11).

## 2. 변경 파일 및 주요 변경
- `frontend/index.html`: Pretendard 웹폰트 링크(jsDelivr), body 배경 클래스 제거.
- `frontend/src/index.css`: `@theme` 토큰 — `--font-sans`, `--text-xs` 13px, `--color-ground`, `--color-accent-50~950`; 표 `tabular-nums`.
- 전 화면(`App.tsx`, `pages/*`, `MenuFormModal`, `RecipeEditorModal`) 클래스 일괄 치환: `slate-*`→`gray-*`, `blue-*`→`accent-*`, 선택 상태를 진한 채움 → 옅은 틴트+진한 글자, `font-black/extrabold`→`font-bold`, 8~11px→12px, `rounded-xl/2xl`→`rounded-lg`, 휴지 상태 그림자·대문자 자간 라벨 제거.
- `App.tsx`: 상단 바 블러 제거, 색 배지 → 평문 지표(`dl`), 도트 홀 스위치 ON 색 near-black, 사이드바 활성 항목 중립 회색 + `aria-current`, `/home`에 h1 `/ 홀 테이블`, S00 위저드의 알약 라벨 → 단계 문장.
- 각 화면 h1을 명사형(`분석`, `입고 · 재고`, `설정` 등)으로, 개발용 `화면 Sxx · REQ-xxx` 라벨과 본문 `(Sxx)`/`(REQ-xxx)` 제거. `PROVISIONAL P-12` 문구는 부제로 이동해 유지.
- 이모지 `✓`/`⚠️` 제거, 회색 400 문구 → 500(대비 4.5:1 이상).
- 숫자 열 우측 정렬(분석 원가표, 재고 현황·입고 이력, 메뉴 판매가), 표 헤더 배경 띠 제거, 숫자 `font-mono`→`tabular-nums`(CSV 원문·주문번호는 mono 유지).
- `AnalyticsPage`: 고원가율 메뉴 0개일 때 경고색 대신 잉크색, 원가율 미산정 시 녹색 `%` 대신 회색 `—`.
- `PixelFloorMap.tsx`: 루트에 `data-ui`만 추가(그림 변경 없음).
- `.gitignore`: `.taste-skill/` 추가.
