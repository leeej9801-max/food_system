# IR-20261025-004 POS 모드(A/B/C) 설정 및 CSV 판매 데이터 수집·매핑 구현보고서

## 1. 작업 요약
- **관련 작업지시서:** [[06_작업지시서/WO-20261025-004_POS설정_및_CSV판매수집]] (`C` 단계)
- **구현 내용:**
  1. **백엔드 DB/API (`REQ-003`, `REQ-004`, `REQ-011`):**
     - `pos_connections`, `pos_product_mappings`, `import_batches`, `sales_orders`, `sales_order_items` 테이블 및 마이그레이션 `0004_pos_imports_and_sales.py` 작성.
     - POS 수집 모드(A: `TOSS_OPEN_API`, B: `TOSS_PLUGIN`, C: `CSV_UPLOAD`) 조회/변경 API 구현 — 모드 A/B는 항상 `UNVERIFIED`, 모드 C는 `READY_CSV` 및 `is_realtime=false`로 반환.
     - CSV 미리보기(`POST /imports/sales-csv/preview`): SHA-256 파일 해시 중복 검사(`duplicate_file_warning`), 행별 주문번호·상품명·수량·단가·시각 검증, 메뉴 마스터 및 `PosProductMapping` 대조.
     - CSV 확정 반영(`POST /imports/sales-csv/{batch_id}/commit`): `(store_id, external_order_id)` 기준 멱등 업서트(중복 합산 방지), `CANCELLED` 행 순매출·순수량 제외, `last_synced_at` 및 `latest_data_time` 갱신.
     - 외부 상품명 매핑(`POST /integrations/mappings`): 미매핑 상품명을 내부 메뉴에 연결하고 기존 `SalesOrderItem`을 `MAPPED`로 소급 갱신.
  2. **프론트엔드 (`S01` + `S02` + 헤더):**
     - `SettingsPage.tsx` 상단에 `S01` POS 데이터 수집 어댑터 선택 카드(A/B/C), 양식당 샘플 CSV 로더/로컬 파일 선택, 컬럼 매핑, 미리보기 검증 표, 확정 반영 버튼, 미매핑 외부 상품명 → 내부 메뉴 즉시 연결 UI 추가.
     - `HomePage.tsx` 상단 카드 및 `App.tsx` 글로벌 헤더에 실제 수집된 순매출·완료 주문 수·마지막 수집 시각 연결.
