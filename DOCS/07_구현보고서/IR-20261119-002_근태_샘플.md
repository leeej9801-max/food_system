# 설정 샘플 데이터에 근태 추가

- S07의 기존 버튼이 시드 API를 호출한다. `app/core/config.py`, `app/api/v1/endpoints/stores.py`, `compose.yaml`에 기본값이 꺼진 `DEMO_SEED_ENABLED`를 연결했다.
- `app/services/demo_seed.py`에서 같은 매장 잠금과 요청 범위를 사용한다. 가상 직원 5명의 최근 28일과 향후 14일 영업일 교대를 만든다. 근태 원본은 결정적 ID로 추가하며, 수기 직원은 수정하지 않는다.
- 09:00–18:00 매장의 14:20 첫 시연은 11:30–12:30 정시, 12:42 지각, 13:15 조기퇴근, 13:45 초과 퇴근, 13:00 출근 후 근무 중, 13:00–14:00 미출근, 14:30 출근 예정을 표시한다.
- 실제 시각과 영업시간에 맞춰 당일 예시를 구성한다. 영업 초반·마감 직전·휴무에는 표시 가능한 상태가 줄어든다. 같은 날 원본 생성 후 재요청하면 타임라인을 보존한다. 다음 영업일 이후 재요청 시 이전 열린 샘플 근무에 퇴근 원본을 추가한다.
- `tests/attendance_sqlite/test_attendance.py`에서 API 플래그, 기존 직원 보존, 시간표·근태 세션 및 재호출을 확인했다. `tests/api/test_pnl_units_seed.py`의 기존 가상 직원·교대 수 검증을 갱신했다.
- 격리 테스트 명령은 `uv run pytest -q --confcutdir=tests/attendance_sqlite tests/attendance_sqlite`다. 59개 통과, PostgreSQL 검사 1개 건너뜀. Ruff와 변경 파일 Pyright, 프론트 타임라인 함수의 7개 상태 검증을 통과했다.
- 격리 PostgreSQL URL이 없어 PostgreSQL API·RLS는 미검증이다. 브라우저 화면과 운영 배포는 미검증이다.
