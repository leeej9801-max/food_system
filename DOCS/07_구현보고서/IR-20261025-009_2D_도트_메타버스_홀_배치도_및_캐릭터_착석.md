# IR-20261025-009 2D 도트 메타버스풍(ZEP 스타일) 매장 홀 테이블·의자·인원수 연동 도트 캐릭터 착석 및 배치 이동 모드 구현보고서

## 1. 작업 요약

- **관련 작업지시서:** [[WO-20261025-009_2D_도트_메타버스_홀_배치도_및_캐릭터_착석]]
- **배경:** 사용자가 공유한 2D 탑다운 도트 메타버스(ZEP 스타일) 레퍼런스 이미지 및 4회차 인터뷰([[인터뷰_기록#4회차]], `U-11`, `U-12`) 결정에 맞춰, `HOME(S02)` 좌측 홀 배치 구역을 **도트 우드 마룻바닥 + 상단 칠판/카운터 벽면 + 도트 식탁·의자 + 착석 인원수(`party_size`)만큼 의자에 앉는 도트 캐릭터 + 말풍선** 구조로 구현하고, 홀 내부에서 **`배치 이동 모드`**로 테이블 좌표를 자유롭게 옮길 수 있도록 연결했다.

---

## 2. 주요 구현 내역

### 2.1 2D 도트 메타버스 홀 컴포넌트 (`frontend/src/components/PixelFloorMap.tsx`)
1. **상단 양식 비스트로 오픈 키친 · 와인 셀러 · 벽돌 화덕 · 출입구:**
   - 사용자가 제시한 양식 비스트로 레퍼런스 이미지에 맞춰 좌측 상단에 **올리브그린 양개 도어 + `WELCOME` 매트 + `Good Food Wine` 입간판**, 중앙 좌측에 **와인 셀러(와인병 진열장) + `BISTRO` 흑판 메뉴 보드**, 우측에 **불꽃이 타오르는 반원형 벽돌 화덕 + 하얀 조리모를 쓴 도트 셰프 아바타 + 서빙 쇼케이스 및 5개 원형 바 스툴**을 구현했다.
2. **헤링본 우드 타일 바닥 & 좌측 빈티지 레드 러그 & 벽등:**
   - 대각선 헤링본(Herringbone) 나무 마룻바닥 패턴과 좌측 빈티지 러그, 우측 벽등 조명을 배치해 따뜻한 양식당 분위기를 재현했다.
3. **정사각 원목 식탁 (`[T1]` 명판 + 중앙 꽃병) & 착석 인원수(`party_size`)대로 마주 보고 앉는 도트 캐릭터 (`BistroSideSeat`, `BistroTopBottomSeat`):**
   - **빈 테이블일 때:** 정사각형 원목 식탁 중앙에 작은 도자기 꽃병이 놓이고 하단 중앙에 검은색 `[T1]` 번호판과 상·하·좌·우 빈 원목 의자가 표시된다.
   - **착석 시작 후 (`SEATED` / `PAID`):** 입력된 `party_size` 인원수만큼 좌·우(1~4인) 및 상·하(5~8인) 의자에 도트 캐릭터들이 식탁을 마주 보고 앉으며, 식탁 위에는 **스테이크 접시·파스타 접시·레드 와인잔·중앙 촛불(캔들)**이 차려진다. 결제 완료(`PAID`) 시에는 식탁 위 영수증·동전과 상단 황금색 말풍선(`T2 · 결제완료`)으로 전환된다.
4. **홀 배치 이동 모드 (`배치 이동 모드`):**
   - 우측 상단 보드의 `배치 이동 모드 켜기` 버튼을 누르면 마룻바닥의 빈 좌표 칸(`col, row`)이 점선 타켓(`+ 여기로 이동`)으로 활성화된다.
   - 이동할 테이블을 선택한 뒤 원하는 빈 바닥 칸을 터치하면 `PATCH /api/v1/stores/{store_id}/tables/{table_id}`를 호출해 `(grid_x, grid_y)` 좌표를 즉시 갱신·저장한다.
5. **상단 내비게이션 iOS 슬라이딩 스위치 (`2D 도트 홀 ON/OFF`) 및 전 화면 이모지 제거:**
   - 홀 배치 영역의 공간 손실을 줄이기 위해 상단 헤더(`App.tsx`)에 아이폰 스타일 슬라이딩 토글 스위치(`2D 도트 홀 ON / OFF`)를 배치하고 불필요한 안내 문구와 전 화면의 유니코드 이모지를 모두 제거했다(`localStorage` 상태 유지).
