## 2. 변경 파일 및 주요 변경
- `backend/tests/conftest.py`: SQLite·`create_all` 삭제. `RLS_TEST_DATABASE_URL`이 없으면 테스트가 시작하지 않는다. 테스트마다 owner로 TRUNCATE.
- `backend/app/db/models/__init__.py`, `backend/alembic/versions/0001~0008`: `String(36)` → `Uuid`. `new_uuid()`가 UUID v7을 만든다. RLS 함수 `app_current_store_id()`가 `uuid`를 돌려준다.
- `backend/app/repositories/`: 표별 파일 15개. 함수는 `Session`을 받고 commit하지 않는다.
- `frontend/src/components/{MenuFormModal,RecipeEditorModal}.tsx`, `frontend/src/pages/HomePage.tsx`: effect 안 setState를 렌더 중 비교로 바꿈.
- `frontend/eslint.config.js`, `frontend/package.json`(`lint` = `eslint . --max-warnings 0`), `.github/workflows/ci.yml`, `lefthook.yml`, `AGENTS.md`.

## 3. 실행한 명령
```
cd backend
RLS_TEST_DATABASE_URL=postgresql+psycopg://owner:ci-only@127.0.0.1:55432/rls uv run pytest -q
uv run ruff check . && uv run ruff format --check . && uv run pyright
cd ../frontend && npm run lint && npm run typecheck && npm test && npm run build
```
로컬 PostgreSQL은 일회용 컨테이너(`postgres:17-alpine`, 127.0.0.1:55432)다.

## 7. 기술 부채 / 위험
- **운영 DB 초기화 필요.** 리비전 ID가 같아서 운영 DB에서 `alembic upgrade head`는 아무것도 하지 않는다. 다음 재배포 전에 [[ADR-016_ID_네이티브_uuid_v7]]의 절차대로 초기화한다. 실행은 사용자 확인 뒤.
- `pool_pre_ping`이 끊긴 연결을 실제로 거르는지는 DB 재시작 시험을 하지 않았다(미검증).
- 번들 537 kB. 화면별 지연 로딩으로 줄일 수 있다(미적용).
- 남은 SQLite 흔적: `backend/app/db/session.py`의 `check_same_thread`, 모델의 `sqlite_where`, `visit_profile.py`의 시간대 보정. 동작에는 영향 없음.
