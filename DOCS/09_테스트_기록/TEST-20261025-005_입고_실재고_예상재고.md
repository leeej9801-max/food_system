## 2. 수용 기준(AC) 대비 검증 매핑

- **AC-1 & AC-2 (`test_ac1_ac2_receipts_preserve_price_history_and_convert_units`):**
  - `2 kg`(`conversion_factor=1000`) 입고 시 `2000 g` 환산 및 구매단위당 단가·기본단위당 단가가 결정론적 코드로 계산됨.
  - 2회 입고(`24,000원` → `12원/g`, `30,000원` → `15원/g`) 시 과거 입고 단가 이력이 덮어써지지 않고 2건 모두 보존되며 최신 입고 단가(`15원/g`)가 요약에 반영됨.
- **AC-3, AC-4 & AC-5 (`test_ac3_ac4_ac5_theoretical_consumption_actual_count_separation_and_alerts`):**
  - 까르보나라(관찰레 `50g`) 완료 판매 4건(`200g`)은 차감되고 취소 판매 2건은 제외되어 예상 재고 `300g`(`LOW_STOCK`)으로 산출됨.
  - 폐기 `-350g` 반영 시 예상 재고 `-50g`(`NEGATIVE_WARNING`)으로 전환됨.
  - 실재고 실사 `450g` 입력 시 `last_actual_quantity=450g`과 `estimated_quantity=450g`이 명확히 분리 표시되고 기준점이 리셋됨.
