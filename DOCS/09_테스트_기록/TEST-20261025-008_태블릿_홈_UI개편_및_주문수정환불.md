## 2. 신규 검증 시나리오 (`test_wo008_sales_order_refund_and_pos_vs_csv_mode_branching`)

1. **`CSV_UPLOAD` 모드에서 현장 수동 주문 등록 (`POST /api/v1/stores/{store_id}/sales-orders`):**
   - `봉골레 파스타` 2개(30,000원) 주문 생성 시 `SalesOrder` 및 `SalesOrderItem`이 생성되고, `S05` 예상 재고 요약에서 레시피 기준 이론 소모량(`200g`)이 즉시 차감되어 예상 재고 `800g`으로 계산됨을 확인.
2. **주문 품목 수량 수정 (`PATCH /api/v1/stores/{store_id}/sales-orders/{order_id}`):**
   - 품목 수량을 2개 → 3개(45,000원)로 변경 시 이론 소모량이 `300g`, 예상 재고가 `700g`으로 즉시 재계산됨을 확인.
3. **주문 환불/취소 전환 (`order_status: "CANCELLED"`):**
   - 환불 처리 시 주문 및 품목 상태가 `CANCELLED`로 변경되고, 이론 소모량이 `0g`, 예상 재고가 초기 입고량인 `1000g`으로 즉시 복원됨을 확인.
4. **POS 연동 모드(`TOSS_OPEN_API`) 전환 시 수동 수정 차단 (`409 Conflict`):**
   - 수집 모드를 `TOSS_OPEN_API`로 전환하면 `GET /sales-orders`의 `can_manual_edit`이 `False`가 되며, 수동 `PATCH` 요청 시 `409 Conflict` (`POS_MODE_MANUAL_EDIT_LOCKED`)가 반환됨을 확인.
