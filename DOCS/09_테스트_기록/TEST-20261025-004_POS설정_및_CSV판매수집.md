## 3. 수용 기준(AC) 대비 검증 매핑

- **AC-1 (`test_ac1_pos_mode_unverified_vs_ready_csv`):**
  - 기본 모드 `CSV_UPLOAD`는 `connection_status="READY_CSV"`이며 `is_realtime=False`.
  - 모드 A(`TOSS_OPEN_API`) 및 모드 B(`TOSS_PLUGIN`) 전환 시 항상 `connection_status="UNVERIFIED"`를 반환하여 실제 자격증명·장비 미검증 상태를 과장하지 않음.
- **AC-2 (`test_ac2_ac3_ac4_ac5_ac6_csv_preview_commit_dedup_cancellation_and_mapping`):**
  - 6행 CSV 미리보기 시 유효 4행, 오류 2행(빈 주문번호, 수량 0), 미매핑 상품(`부채살 스테이크`) 정확히 분류.
- **AC-3 & AC-5:**
  - 커밋 시 `CANCELLED` 행(`ORD-103`)은 순매출(`75,000.00원`)과 완료 주문 수(`2건`), 순수량(`4개`)에서 제외됨.
- **AC-4:**
  - 동일 파일 재업로드 시 `duplicate_file_warning=True`가 표시되며, 재커밋하더라도 `(store_id, external_order_id)` 멱등 덮어쓰기로 순매출이 중복 합산되지 않음(`75,000.00원` 유지).
- **AC-6:**
  - 미매핑 외부 상품명(`부채살 스테이크`)을 내부 메뉴(`채끝 스테이크(메뉴마스터)`)에 연결하면 기존 `SalesOrderItem` 1건도 즉시 `MAPPED`로 소급 갱신되고 `unmapped_products` 목록이 비워짐.
