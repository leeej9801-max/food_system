## 2. API 테스트 (SQLite, `backend/tests/api/test_visit_profile_api.py`)
- 테이블 방향 `V`와 확장 좌표(23, 27) 저장. 범위 밖 좌표(24)와 잘못된 방향은 422.
- 도면 프리셋: 처음 실행 시 생성 10, 갱신 2(T1·T2 재사용). 두 번째 실행 시 0/0. 12테이블(세로 4), 모두 4인석, 좌표가 프리셋과 같음. 고정물에 입구·카운터·주방·칸막이 포함.
- 손님 성별·연령: 남의 자리는 403, 자기 자리는 저장됨. 손님이 넣은 자리를 직원이 바꾸면 409 `SLOT_PROFILE_BY_GUEST`. 직원은 빈 자리를 채움. 대표 연령은 섞이면 `MIXED`, 같아지면 그 값.
- 직원 자리 입력: 없는 자리는 `SLOT_NOT_FOUND`, 없는 방문은 `VISIT_NOT_FOUND`.
- 방문 목적·관계: 직원 입력 뒤 손님 입력이 덮어씀. 그 뒤 직원 변경은 409 `CONTEXT_BY_GUEST`. 인원 수정은 그대로 됨. 잘못된 선택지는 422.
- 종료 시각 계산: 11:00-21:00 매장에서 12:00 착석 → 퇴점 21:00, 닫기 다음 날 11:00. 17:00-02:00 매장에서 01:00 착석 → 같은 날 02:00 퇴점. 읽을 수 없는 영업시간(빈 값, "늘 영업", "25:00-10:00")은 계산하지 않음.
- 자동 닫기: 같은 날 밤(종료 후, 다음 영업 전)에는 닫지 않음. 다음 영업 시작 후 테이블 목록을 열면 `LEFT`·`END_OF_DAY`, 퇴점 시각은 21:00 KST.
- 영업시간을 읽을 수 없으면 닫지 않음. 영업시간을 고친 뒤 손님 QR로 열면 지난 세션에 합류하지 않고 새로 열며, 지난 세션은 `END_OF_DAY`로 닫힘.
- 공휴일: 수동 추가 201, 같은 날짜 409 `HOLIDAY_EXISTS`, 연도별 조회. `day_type`은 2026-12-25 HOLIDAY, 12-26 WEEKEND, 12-24 WEEKDAY.
- 천문연 응답 해석: 여러 건, 한 건(객체), 빈 결과, 오류 코드를 처리함. `isHoliday=N`은 제외함. **실제 인증키로 호출하지 않았다(`미검증`).**
- 개인정보: 새 컬럼에 이름·연락처·생일·별명이 없음.
