# 손님 객층·날씨 분석

## 목표
- 홈(홀)에서 받는 연령대·성별·동반 관계·팀 인원을 분석 화면에서 대시보드로 본다.
- 일별 날씨(기상청 ASOS 일자료)를 저장해 날씨와 매출·손님 유형·팔린 메뉴를 묶어 본다.

## 범위
- 백엔드: `weather_daily` 테이블(전역, 0013 마이그레이션), `scripts/fetch_weather.py` 수집 스크립트, `GET /stores/{store_id}/analytics/guests`.
- 프론트: 분석 화면 아래에 손님 연령대·동반 관계·팀 인원(성별)·관계별/연령대별 많이 팔린 메뉴·날씨별 매출 카드.

## 규칙
- 주문↔방문 연결: 주문 시각이 착석~퇴장(또는 현재) 구간과 겹치는 방문이 정확히 하나일 때만 연결. 둘 이상이면 `겹침`, 없으면 `미연결`. 화면에 `추정` 표시(PROVISIONAL).
- 날씨 구간(PROVISIONAL): 강수 1mm 이상 = 비 온 날, 평균기온 5/15/25도 경계.
- 날씨는 영업한 날(매출 또는 방문 있음)만 집계.

## 미검증
- 기상청 API 실제 호출(키·관측소 미확인). `KMA_SERVICE_KEY`, `KMA_STATION_ID`를 `backend/.env`에 넣고 `uv run python -m scripts.fetch_weather <시작일> <종료일>`로 수집한다.
- 관측소 번호는 사장님 확인 필요(U-28: 소풍터미널 인근).
- 매일 자동 수집 스케줄 없음(수동 실행).
