# 손익 캘린더 날씨 아이콘 (U-56)

## 목표
- 손익 화면 일별 캘린더 날짜 옆에 비·눈·강수 없음 아이콘을 둔다. 마우스를 올리면 강수량과 최고·최저 기온을 보인다.

## 구현
- 수집: 기상청 API허브 `nph-aws2_min`(AWS 매분자료, 지점 433 부천). 하루 1회 호출(여러 날을 한 번에 주면 마지막 1440분만 온다).
- 일값: 기온(TA) 평균·최저·최고, 일강수(RN-DAY)는 그날 최댓값(00:00 행은 전날 누적이라 뺀다). 결측(-99.x) 제외.
- `GET /api/v1/weather?month=YYYY-MM`: 저장 안 된 지난 날은 받아 저장, 오늘은 1시간 메모리 캐시, 미래는 비움. 실패한 날은 비워 두고 다음 요청에서 다시 받는다.
- `backend/scripts/fetch_weather.py <시작> <끝>`: 지난 기간 한꺼번에 채우기.
- 설정: `backend/.env`의 `KMA_APIHUB_KEY`, `KMA_STATION_ID=433` (키는 커밋 금지).
- 프론트: `src/api/weather.ts`, `weatherMonthSchema`, `PnlPage` `WeatherIcon` (Antigravity Gemini 4 Hydrogen 작업).

## 검증 (실행함)
- backend pytest 전체 126 통과(OpenAPI 스냅숏·프론트 표본 갱신), ruff 통과.
- 실제 API로 2026-11-01~16 부천 자료 저장 확인(일부 날 시간초과 → 재실행으로 채움).
- frontend tsc·eslint·vitest 85 통과. 브라우저 1280px `/pnl`에서 아이콘 16개와 라벨 확인(DOM 기준).

## 미검증 / 남은 일
- 구름·맑음 구분 없음(API허브 `nph-aws2_min_cloud`·`ww1` 활용신청 필요, 403).
- 눈 판정 기준(최고 1°C 이하) PROVISIONAL, 실제 눈 날 미검증.
- 첫 달 조회는 30일 × 약 4~5초를 8개 병렬로 받아 수십 초 걸릴 수 있다. 매일 자동 수집 스케줄러 없음.
- 태블릿·폰 실기기 확인 안 함.
