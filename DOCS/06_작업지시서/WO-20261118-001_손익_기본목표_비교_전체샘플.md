# 손익 기본 목표·기간 비교·전체 샘플

## 목적과 범위
사용자 지시: 매장 기본 매출/영업이익 목표와 월별 필드별 덮어쓰기, 기존 KPI 디자인을 유지한 비교 선택, 설정 샘플 버튼으로 전 화면 공통 데이터를 갱신한다. S01/S02/S05/S06/S07, ADR-014의 동기 3계층을 유지한다. 기존 미커밋 변경을 보존하며 commit/push, 패키지/lock/skill/agent/환경파일, DOCS 이미지·zip 변경은 하지 않는다.

## 구현과 수용 기준
- Store 기본 목표 nullable bigint + 0015 migration. 기존 PUT goal에 scope(default|month, 기본 month)를 더한다. 월 null은 필드별 기본 fallback, 0은 명시적 월 값. 응답에 원본 기본/월 값과 필드별 source(default|month)를 준다. 기본 변경은 다른 월 캐시도 무효화한다.
- 기존 전월 동기와 주단위/월평균 단위/주평균 단위를 선택하고 매출·지출·이익의 비교 금액과 기준을 표시한다. ⓘ는 터치/키보드 지원. kpiDelta 재사용.
- PROVISIONAL 계산 가정: 현재 월은 매장 timezone 오늘을 기준으로, 과거 월은 말일을 기준으로 한다. 미래 월은 새 비교 미산출. 주단위는 기준일이 속한 월요일~기준일과 7일 전 같은 범위. 주평균은 직전 4개 완료주(월~일)의 평균과 이번 주 진행분을 비교한다(불균등 기간임을 UI에 명시). 월평균은 선택월 합계와 직전 N개 완료월 평균(N=3, API 1~6). 현재 월 고정비는 현재 손익표와 동일한 입력 월액이다. 주 비교는 각 월 확정 손익을 달력 일수로 안분하되 자동 판매/입고는 실제 일자, 월 수기 덮어쓰기는 해당 월액을 일수로 안분한다. 계산은 Decimal, 최종 원 단위 반올림. 이전 자료 없는 구간은 0으로 발명하지 않고 미산출, 평균 기준 구간 중 하나라도 기록이 없으면 미산출.
- 샘플은 고정 난수, 매장 timezone 기준 최근 6개 완료월+현재월 오늘까지(2026-11-18이면 5/1~11/18). 영업일 설정 준수(미설정이면 월 휴무 가정), 점심/저녁 패턴, 매출/방문/슬롯/입고/가격/재고/고정비를 같은 원천으로 생성한다. 재료비 30~35%, 영업이익률 10~20%를 자동 검증. 샘플 식별 기록만 교체하고 사용자 자료는 보존. 실명/개인정보 없음. 실 POS 미검증.
