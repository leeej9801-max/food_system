# 카카오 실계정 · 병합/출시 전 검증 (후속 DRAFT)

이번 구현자의 실제 계정 로그인/운영 배포는 금지 범위이므로 아래는 수행하지 않은 후속 작업이다. 사용자 또는 후속 담당자는 IR의 수동 절차를 따른다.

- 카카오 실제 앱·닉네임 동의·등록 Redirect URI·HTTPS 주소를 설정하고 초대→PENDING→점주 승인→QR IN/OUT→모달 폴링 완료를 실제 직원 폰에서 검증한다. 비밀·쿠키·code·QR 원문을 증거에 남기지 않는다.
- 개발 8001 callback과 실제 폰 접근 주소 차이를 사용자가 해결한다. 이번 에이전트는 8001/5174에 접근하지 않았다.
- 병합 담당자는 손익 0014_monthly_goals와 attendance 0014~0016의 번호/head를 정리한 뒤 격리 DB에서 migration/rollback/권한 검사를 재실행한다.
- 운영 프록시/플랫폼 접근 로그의 OAuth query 가림, HttpOnly/SameSite/Secure, Origin, refresh 만료/폐기와 점주 인증을 독립 검토한다.
- 법정 보관/열람/정정/탈퇴·급여 요건을 확인한다. 위치/QR 전달 위험은 제품 판단으로 남긴다.

수용 기준은 실제 검증 증거와 미확인 범위가 분리된 후속 IR/REV다. 이 DRAFT는 운영 배포 승인이나 미확인 요구사항 확정을 뜻하지 않는다.
