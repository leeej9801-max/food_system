# WO-20261025-009 2D 도트 메타버스풍(ZEP 스타일) 매장 홀 테이블·의자·인원수 연동 도트 캐릭터 착석 및 배치 이동 모드 구현

## 1. 작업 배경 및 목표

사용자가 제시한 2D 탑다운 메타버스(ZEP / 개더타운 스타일) 레퍼런스 이미지와 4회차 인터뷰([[인터뷰_기록#4회차]], `U-11`, `U-12`) 결정에 따라, `HOME(S02)` 좌측 매장 홀 영역을 **도트 우드 마룻바닥 · 상단 칠판/카운터 벽면 · 도트 식탁 및 의자 · 착석 인원수(`party_size`)에 맞춰 의자에 앉는 도트 캐릭터 · 말풍선 상태창**으로 시각화한다. 또한 홀 화면 안에서 **`배치 이동 모드`** 토글을 통해 마룻바닥의 원하는 좌표 칸(`grid_x`, `grid_y`)을 터치하여 테이블 위치를 자유롭게 배치할 수 있게 한다.

---

## 2. 구현 범위

1. **2D 도트 메타버스 홀 캔버스 컴포넌트 (`frontend/src/components/PixelFloorMap.tsx`):**
   - **벽면 & 카운터 구역:** 레퍼런스 이미지 감성의 상단 벽면 보드(매장 현황 칠판, 오더 보드)와 카운터 데스크 + 매니저/셰프 도트 캐릭터 배치.
   - **도트 우드 플로어 그리드 (`4열 × 3행` 기본 12칸, 테이블 수에 따라 자동 확장):** 나무 마룻바닥 패턴과 픽셀 테두리 스타일 적용.
   - **도트 식탁 & 의자 기본 렌더링:**
     - 테이블 좌석 수(`seats`)에 맞춰 식탁 주변(상·하·좌·우)에 도트 나무 의자를 배치.
     - 빈 테이블일 때는 깔끔한 식탁과 빈 의자로 표시.
   - **착석 시작 시 인원수(`party_size`) 연동 도트 캐릭터 착석:**
     - `active_visit`이 존재하면 `party_size` 명수만큼 의자 위치에 귀여운 도트 아바타 캐릭터(머리·표정·상의 컬러 및 연령대 포인트 반영)가 앉아 있는 모습을 렌더링.
     - 식탁 위에는 식사 중(`SEATED`)일 때 플레이트/파스타·음료 도트 오브젝트를, 결제 완료(`PAID`)일 때 계산서·코인 도트 오브젝트를 표시.
     - 테이블 상단에는 ZEP 스타일 픽셀 말풍선(`테이블명 · N명 · 연령대`)을 띄운다.
   - **홀 배치 이동 모드 (`배치 이동 모드` 토글):**
     - 활성화 시 마룻바닥의 빈 좌표 칸(`col`, `row`)이 점선 타일로 표시되며, 선택된 테이블을 원하는 빈 칸 터치 한 번으로 즉시 이동(`PATCH /api/v1/stores/{store_id}/tables/{table_id}`)시킨다.
2. **HOME 페이지 연동 (`frontend/src/pages/HomePage.tsx`):**
   - 좌측 홀 영역에 `PixelFloorMap`을 탑재하고, 우측 터치 패널에서 착석/인원 변경/결제/퇴점 시 도트 홀의 캐릭터 수가 실시간으로 즉시 반영되도록 연동한다.

---

## 3. 수용 기준 (Acceptance Criteria)

- **AC-1:** 빈 테이블은 도트 식탁과 좌석 수만큼의 빈 도트 의자로 표시되고, 착석 시작 시 입력한 `party_size`(인원수)만큼 도트 캐릭터가 의자에 앉아 표시된다.
- **AC-2:** 우측 패널에서 인원수 또는 연령대 스텝퍼를 수정 저장하거나 퇴점(`LEFT`) 처리하면, 도트 홀의 착석 캐릭터 수와 말풍선·식탁 위 오브젝트가 즉시 동기화된다.
- **AC-3:** `배치 이동 모드`를 켜고 마룻바닥의 빈 타일을 터치하면 선택된 테이블의 `(grid_x, grid_y)` 좌표가 DB에 업데이트되어 해당 위치로 이동한다.
