# 설정 샘플 데이터에 근태 추가

- S07 양식당 샘플 요청에 근태 데이터를 추가한다. 동기 3계층(ADR-014)과 기존 매장 범위를 유지한다.
- 운영에서는 기본 404를 유지한다. 시연은 `DEMO_SEED_ENABLED`로 명시적으로 연다.
- 결정적 ID로 가상 직원 5명, 최근 28일과 향후 14일의 영업일 교대, 출퇴근 원본을 생성한다. 수기 직원과 원본 이벤트를 보존한다.
- 오늘은 매장 시간이 허용하는 범위에서 근무 중, 지각, 조기퇴근, 초과, 정시, 출근 예정, 미출근을 표시한다.
- 설정, API, 시드 서비스, Compose, 테스트만 수정한다. Ruff, Pyright, 관련 pytest, 커밋 훅을 실행한다. 격리 PostgreSQL URL이 없으면 해당 검증을 보류한다.
