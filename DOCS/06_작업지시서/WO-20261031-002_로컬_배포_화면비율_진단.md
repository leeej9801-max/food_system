# WO-20261031-002 — 로컬/배포 화면 비율 진단

사용자 증상: 같은 브라우저에서 로컬100%일 때 맞던 화면을 외부 도메인에서는 약67%로 줄여야 볼 수 있음. Lenovo IdeaPad Flex5 기준.

범위: S02 및 공통 셸의 실제 viewport/브라우저 배율/배포CSS·로컬CSS 비교. 동일 CSS viewport에서 레이아웃 재현을 확인하고 원인이 확인되면 최소 수정/재배포. 정상 로컬 디자인이나 저장 데이터는 임의 변경하지 않는다.

수용 기준: 실제 측정으로 원인과 추측 구분, 비교 스크립트/스크린샷 또는 CSS 차이 근거 기록, 필요한 수정에 대한 검증, IR→REV(self-review)→인수인계 갱신. 부하/DB/POS 변경은 제외.

## 범위 갱신 — 사용자 후속 요청
사용자가 이전 로컬 확대율을 잘못 기억했을 수 있다고 설명하고, 현재 노트북에서 브라우저100%로67% 크기를 보도록 요청했다. 기존 진단 결과는 유지하고, 이 요청을 명시적인 새 밀도 설정으로 구현한다.

- 공통 CSS에서 너비1024~1535px·높이900px 이하·정밀 포인터 환경에67% UI 밀도 적용. 모바일/큰 화면은 기존 배치 유지. 새 패키지·DB/API 변경 없음.
- CSS zoom에 맞춰 홈 최소 높이·앱 최소 높이·주문 팝업 최대 높이의 viewport 단위를 보정한다.
- 기존 와인/Pretendard/도트 홀 디자인 유지. 질문: 한 화면에서 홀과 방문 상태를 얼마나 함께 볼 수 있는가. 실제6테이블·17명·기존 업무 데이터로 검증하고 새 샘플 데이터는 만들지 않는다.
- 로컬/배포 브라우저100%, 다른 크기에서 CSS 적용 범위, 팝업·가로 넘침, frontend 테스트·빌드 및 외부URL 확인 후 웹 컨테이너만 재배포.
