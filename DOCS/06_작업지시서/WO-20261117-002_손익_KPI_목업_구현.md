# 손익 KPI 승인 목업 구현

S06/손익 확장, ADR-014. 사용자 지시와 `design/mockups/pnl_calendar/mockup_kpi.html` 및 매출/이익 PNG를 기준으로 KPI만 구현한다. 기존 미커밋 변경, 달력, 목표 편집 흐름을 보존하며 stage/commit/push하지 않는다.

## 수용 기준

- xl: 동일 폭 3열 + 목표 340px, 16px 간격. 영업이익/매출·객단가/지출, 아래 3열 추이, 목표 2행. sm 2열, mobile 1열, xl 미만 목표 하단.
- 목업 CSS 수치·그라데이션·유리 효과·반원 게이지·막대 탭 구현. 설명은 Astryx Tooltip. 공통 HeroKpi 변경 없음.
- 어제 전체 대 오늘 수집분, 주문 기준 객단가(없으면 미산출), 전월 동기 증감과 작은 기준/부호 전환 예외, 이익률 %p, 영업일 진도. 기본 목표는 API에 없으므로 월별 실제 목표만 설명한다. 목표 aside는 매출만 표시하며 이익 추이에 목표선을 그리지 않는다.
- 주문 집계는 repository → sync service → schema로 추가하며 완료 주문/품목, 시간대, 매장 격리 검증. 새 DB 구조·의존성·POS 연동 없음.

## 변경/검증 계획

PnlPage, 전용 PnlKpis, pnl.css/lib/tests, frontend API schema/types/fixture, backend pnl service/schema/sales_orders repository/tests 및 계약 snapshot. tsc, 변경 파일 eslint, vitest, build, backend 관련 pytest. 브라우저 1280/1024 및 mobile 확인, 미실행은 명시. IR → self-review REV → 인수인계/변경이력/허브 갱신으로 종료한다.
