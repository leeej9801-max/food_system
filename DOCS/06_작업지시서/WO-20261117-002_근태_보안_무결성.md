# 근태 1차 보안·무결성

사용자 지시 1~7을 구현한다. 작업 위치는 feature/attendance worktree만이며 본 저장소 수정·커밋·push는 금지한다. Antigravity의 frontend 공통 헤더·CSS·컴포넌트 변경을 보존한다. frontend 수정은 근태 API 클라이언트 UUID 전송으로 제한한다. ADR-014의 동기 3계층을 유지한다.

- 클라이언트 UUID를 필수 입력으로 받고 UNIQUE(store_id, staff_id, client_event_id)를 적용한다. 키 재요청 또는 같은 직원·kind의 60초 내 요청은 기존 행과 HTTP 200을 반환한다. 새 행은 201이다. 직원 행 잠금으로 PostgreSQL 동시 요청을 직렬화한다.
- 기존 원본·정정 불변 트리거를 유지하고 audit_logs에도 UPDATE/DELETE 차단을 적용한다. audit_logs는 매장 RLS와 추가 전용 권한을 적용한다.
- 직원 생성/수정/비활성화, 스케줄 생성/수정/삭제, 출퇴근 정정을 같은 트랜잭션에서 감사 기록한다. 인증 전 actor는 기존 RequestContext의 PROVISIONAL 식별자를 사용한다.
- 직원 DELETE는 INACTIVE로 바꾸며 기본 목록은 ACTIVE만 조회한다. 과거 원본·정정·스케줄은 보존하고 비활성 직원의 신규 출퇴근은 4xx로 거부한다.
- 다음 리비전 0015 한 개로 상태·키·감사 표·복합 인덱스를 추가한다. 기존 이벤트는 id를 키로 채워 보존한다. upgrade/downgrade를 검증하며 rollback 시 추가 메타데이터 제거 범위를 IR에 기록한다.
- 요구된 pytest 다섯 항목 외에 매장 격리·실패 원자성·키 제약·기존 행 마이그레이션 보존을 확인한다. ruff, pyright, 관련 pytest, tsc를 실행하고 실제 결과를 IR에 쓴다.

인증 설계 §6.5의 법적·운영 미결정은 확정하지 않는다. QR·카카오·기기 인증은 범위 밖이며 관련 로그 원칙은 IR의 다음 단계에만 적는다. design/pnl-ux의 미커밋 0014_monthly_goals와 head 분기는 IR에 남기고 해결하지 않는다.

완료 조건: 요구된 검사 실행과 정직한 결과 기록, IR → self-review REV → 인수인계 갱신. 독립 리뷰·운영 배포는 하지 않는다.

완료: [[IR-20261117-002_근태_보안_무결성]], [[REV-20261117-002_근태_보안_무결성]]. 60초 중복에 쓰인 다른 UUID도 시간창 이후 재시도할 수 있도록 추가 전용 키 연결 표를 포함했다. 이번 마이그레이션은 한 개다.
