# WO-20261025-008 태블릿 현장 입력 친화형 HOME UI 개편, 연령대 터치 스텝퍼, 영업일 터치 설정 및 주문 수정·환불(POS/CSV 분기)

## 1. 작업 배경 및 목표

3회차 사용자 인터뷰([[인터뷰_기록#3회차]], `U-08`~`U-10`) 피드백을 반영하여 사무용 대시보드 느낌이던 `HOME(S02)` 및 전체 셸 레이아웃을 **매장 영업 중 카운터/홀 태블릿 터치 입력에 최적화된 화면**으로 개편한다. 또한 주문 수정·환불(취소) 발생 시 **POS 연동 모드(자동 반영 안내)**와 **CSV 모드(직접 수정·환불 전환·수동 추가)**로 분기하여 재고·원가·판매 집계 파이프라인이 실시간으로 재계산되도록 연결한다.

---

## 2. 범위 (Scope)

### 2.1 프론트엔드 레이아웃 및 화면 개편
1. **사이드 네비게이션 숨기기/접기 및 태블릿 전체 폭 활용 (`App.tsx`):**
   - 상단 헤더 좌측에 `☰ 메뉴 열기 / 숨기기` 토글 버튼을 배치하고, 영업 중 주로 머무는 `HOME(/home)` 진입 시 사이드 네비게이션을 접어둘 수 있게 하여 테이블 배치도와 입력 패널이 태블릿 가로 폭 전체를 넓게 쓰도록 한다.
   - 상단 헤더 바에 현재 매장 요약 지표(`착석 테이블/인원`, `누적 방문 팀/인원`, `순매출(취소제외)`)를 컴팩트한 배지로 통합 표시한다.
2. **초기 매장 생성(`S00`) 및 설정(`S07`) 영업일·운영시간 터치 UI (`App.tsx`, `SettingsPage.tsx`):**
   - `화,수,목,금,토,일` 텍스트 타이핑 대신 **`월` `화` `수` `목` `금` `토` `일` 터치 토글 버튼**과 빠른 프리셋(`월요일 휴무`, `연중무휴`, `평일 영업`)을 제공한다.
   - 운영시간(`11:30-22:00`)도 터치 친화적인 오픈/마감 시간 선택 UI로 구성한다.
   - `SettingsPage.tsx`(`S07`)에서도 매장명·영업일·운영시간을 언제든 터치로 수정(`PATCH /api/v1/stores/{store_id}`)할 수 있게 한다.
3. **HOME(`S02`) 현장 입력 친화형 개편 (`HomePage.tsx`):**
   - 불필요한 기획 설명 문구(`POS에서 자동 수집되는 메뉴·주문은...`, `화면 S02 · REQ-002...`)와 거대한 상단 KPI 카드 3종을 제거한다.
   - **좌측 메인 구역(매장 2D 테이블 배치 홀):** 화면의 가장 넓은 면적을 차지하며, 향후 2D 도트 매장 꾸미기/배치도로 확장하기 좋은 공간감 있는 홀 캔버스와 큼직한 테이블 카드로 구성한다.
   - **우측 선택 테이블 터치 패널:**
     - 중복되던 `- 1명 / 현재 선택: N명 / + 1명` 행을 제거한다.
     - **연령대 터치 스텝퍼(`[-] 10대 (0) [+]`, `[-] 20대 (2) [+]`, `[-] 30대 (1) [+]`, `[-] 40대 (0) [+]`, `[-] 50대 (0) [+]`, `[-] 60대+ (0) [+]`):** 드롭다운 대신 버튼 안의 `-` / `+` 터치로 연령대별 인원을 즉시 증감하며, 조작 시 총 방문 인원수(`guest_count`)가 자동 합산된다. 연령대를 모를 때만 상단 `1명~8명` 빠른 터치 버튼을 누른다.
     - 패널 하단에 **`🧾 주문 수정 · 환불 관리`** 모달 진입 버튼을 배치한다.

### 2.2 백엔드 & 프론트엔드 주문 수정·환불(취소) 상호작용 (`POS vs CSV 모드 분기`)
1. **백엔드 API 추가 (`backend/app/api/v1/endpoints/imports.py`, `backend/app/services/imports.py`):**
   - `PATCH /api/v1/stores/{store_id}`: 매장 기본정보(`name`, `business_days`, `opening_hours`) 수정 엔드포인트 (`stores.py`).
   - `GET /api/v1/stores/{store_id}/sales-orders`: 수집된 주문 목록 및 상세 품목(`SalesOrderItem`), 현재 연동 모드(`pos_mode`), 수정 가능 여부(`can_manual_edit: mode == "CSV_UPLOAD"`) 조회.
   - `PATCH /api/v1/stores/{store_id}/sales-orders/{order_id}`:
     - **POS 모드(`TOSS_OPEN_API`, `TOSS_PLUGIN`)인 경우:** `409 Conflict`로 직접 수정을 차단하고 POS 자동 연동 안내 메시지 반환.
     - **CSV 모드(`CSV_UPLOAD`)인 경우:** 주문 상태(`COMPLETED` ↔ `CANCELLED` 환불/취소 전환) 및 품목별 수량(`quantity`) 수정을 허용하고, `total_quantity`·`total_amount`를 결정론적으로 재계산하며 `AuditEvent`를 기록한다.
   - `POST /api/v1/stores/{store_id}/sales-orders`:
     - **CSV 모드(`CSV_UPLOAD`)인 경우:** 현장에서 누락된 주문을 메뉴 선택 + 수량 터치로 즉시 수동 등록할 수 있는 엔드포인트 제공.
2. **파이프라인 자동 연동 보장:**
   - 주문이 `CANCELLED`(환불)로 변경되거나 수량이 수정되면 `S05` 예상 재고(이론 소모량 차감 복원)와 `S06` 시간대별·메뉴별 판매 집계 및 상단 순매출 배지가 즉시 재계산된다.

## 3. 수용 기준 (Acceptance Criteria)

- **AC-1:** `App.tsx`에서 사이드 네비게이션을 접고 펼칠 수 있으며, 상단 헤더에 컴팩트 요약 배지가 표시되고 `S00`/`S07`에서 요일 버튼 터치로 영업일을 설정·수정할 수 있다.
- **AC-2:** `HomePage.tsx`에서 불필요한 설명 문구·거대 KPI 카드·중복 `-1/+1명` 컨트롤이 제거되고, 연령대 터치 스텝퍼(`- 20대 +` 등) 조작 시 총 방문 인원수와 연령대 문자열이 자동 합산·저장된다.
- **AC-3:** `CSV_UPLOAD` 모드에서 주문의 품목 수량 수정 또는 `CANCELLED`(환불) 전환 시 순매출·판매집계(`S06`)·이론 소모량 및 예상 재고(`S05`)에 즉시 반영되며, `TOSS_OPEN_API`/`TOSS_PLUGIN` 모드에서는 수동 주문 수정이 `409 Conflict`로 차단된다.
