## 1. 목적 / 문제

사용자 요청: `design-taste-frontend` 스킬로 기존 화면(S00~S07)을 리뷰하고 개선한다 (브랜치 `front_check`).

스킬 인스펙터(`inspect.mjs --app`) 사전 측정 결과(`.taste-skill/before/`, 커밋 제외):
- 크롬(상단 바·사이드바·선택 칩)에 파란색 강조색을 넓게 사용 → 데이터보다 장식이 시끄러움.
- 13px 미만 텍스트 비율 57~83% (`tiny-text`), 일부 9~10px.
- `/home`에 h1 없음 (`no-title`), 다른 화면 h1에 `(S01)`, `(REQ-010)` 등 개발용 ID와 "화면 S06 · REQ-…" 상단 라벨(eyebrow) 노출.
- 이모지 `✓`, `✨` 사용 (`emoji` FAIL), 회색 보조 문구 대비 2.6:1 (`contrast`).
- 휴지 상태 카드 그림자, 반투명 블러 헤더, 대문자 자간 라벨, 시스템 기본 서체.

## 2. 범위

### 포함
- 디자인 토큰: 서체(Pretendard), 중립 회색 램프, 단일 강조색 램프(와인), 반경·그림자 정리 — `frontend/src/index.css`.
- 클래스 일괄 치환: `slate-*` → `gray-*`(중립), `blue-*` → `accent-*`(강조색), 선택 상태는 강조색 진한 채움 대신 옅은 틴트 + 진한 글자.
- 셸(`App.tsx`): U-08 구조(접이식 사이드바, 상단 요약 지표) 유지, 색 배지를 평문 지표로, 사이드바 활성 항목을 중립 회색으로, 블러 제거, `/home` h1 추가.
- 각 화면 제목을 명사형으로 정리하고 개발용 ID 라벨 제거. **`PROVISIONAL`/`미검증`/`UNVERIFIED` 표시는 유지** (작업규약 §3-5).
- 이모지 제거, 11px 미만 텍스트 제거(도트 홀 그림 내부 간판 제외), 대비 4.5:1 미만 문구 수정, 숫자 열 우측 정렬·tabular figures.

### 제외 (비범위)
- 2D 도트 홀(`PixelFloorMap`, U-11)의 그림 스타일 — 제품 고유 요소로 유지 (`data-ui`로 표시).
- 화면 구조·데이터 흐름·API·업무 로직 변경, 새 화면, 새 의존성(npm) 추가.
- 셸 구조 변경(고정 사이드바 등) — U-08 사용자 확정 사항이므로 유지.

1. `index.css`에 `@theme`로 `--font-sans`(Pretendard → system 폴백), `--color-accent-50~950` 정의. 사용 이유를 한 줄 주석으로.
2. `index.html`에 Pretendard 웹폰트 링크(jsDelivr) 추가. 오프라인 시 시스템 서체로 폴백.
3. 위 §2 포함 항목 적용. 기능·문구 의미·`data`/`aria` 속성은 바꾸지 않는다.
