## 1. 검토 관점
- [x] 요구사항 충족 — AC-2~AC-5 충족, AC-1은 저장소 전체 서식 검사만 기준선 실패(IR §5)
- [x] 데이터 정확성 — 기존 방문은 STAFF로 채움, 중복 열린 세션은 마이그레이션 전에 중단
- [x] 보안 — 손님 요청의 매장은 서버가 토큰으로 결정, 새 매장 표 RLS FORCE, 토큰 목록 읽기 불가, 기기 토큰 해시 저장
- [x] 예외 상황 — 동시 열기는 부분 고유 인덱스 + 합류, 마지막 슬롯·가져간 슬롯 보호
- [ ] UX — 화면 없음(범위 밖)
- [x] 테스트 커버리지 — SQLite 12개, PostgreSQL 격리 4개 추가
