- 실제 top-level Chromium10개 크기·포인터 조합으로 노트북만0.67, 모바일/터치전용/넓은화면1 확인. 1280×595에서6화면 가로 넘침 없음, 모달배경1280×595·패널viewport내 확인. 스크린샷 직접 검토: 홀/우측패널/하단행동 동시에 보이고 팝업 닫기·내부스크롤 표시. 390과1920 화면도 검토.
