## 검토 중 수정한 항목

- 주간 확장 핸들 교체 시 포인터 캡처가 사라지던 문제를 board 캡처로 수정했다. 실제 11/19→11/21 3일 drag를 확인했다.
- 닫힌 Dialog 안에서 휠 초기 scrollTop이 적용되지 않던 문제를 열림 뒤 초기화로 수정했다. 오전·시·분 선택과 실제 위치를 확인했다.
- 광범위한 mockup button/reset 스타일이 Astryx 버튼을 덮던 문제를 화면 범위의 native button에만 적용하도록 수정했다.
- 미래 기간 카드에 현재 열린 출근이 표시될 수 있던 집계 경계를 수정하고 회귀 검사를 추가했다.
- SQLite 응답 UTC 표기 및 입력 offset 정규화, 수동 수정에서 바꾸지 않은 원본 초 단위 시각 보존을 확인했다.
- 원본·정정은 DB 권한과 트리거로 UPDATE/DELETE/TRUNCATE를 막는다. 역할 설정 재실행 후에도 불변 권한이 유지되는 것을 실제 PostgreSQL에서 확인했다.
- 원본·정정 수정 API가 없고, 서비스가 모든 직원/원본 대상의 매장을 확인한다. 사유·시간 순서·최소 시간·스케줄 겹침·야간 경계·휴무·점주 공백 제외 검사가 있다.
- CSS는 `@layer components` + `.attendance-page` 안에 있다. 전역 셸이나 기존 화면의 CSS를 변경하지 않았다.
