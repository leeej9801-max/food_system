# 근태 샘플 자체 리뷰

- 날짜별 교대와 세션이 프론트의 5분 허용 기준에서 7개 상태에 해당함을 확인했다.
- 시드 식별자는 매장과 직원, 교대, 이벤트에 따라 고정된다. 같은 날 재호출의 ID와 원본 시각, 다음 날 재호출의 기존 원본을 검증했다.
- 운영 opt-in 기본값과 실제 API 실행을 SQLite에서 검증했다.
- 남은 검증은 일회용 PostgreSQL의 API·RLS 실행과 브라우저 화면 확인이다.
