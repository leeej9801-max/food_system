# REV-20261025-009 2D 도트 메타버스풍 매장 홀 배치도 및 캐릭터 착석 셀프 리뷰

## 1. 리뷰 결과: PASS

- **AC-1 (기본 도트 식탁·의자 및 착석 인원수 연동 도트 캐릭터):** 빈 테이블일 때는 좌석 수만큼 빈 도트 나무 의자가 표시되고, 착석 시작 시 `party_size` 인원수만큼 도트 캐릭터가 의자에 앉아 표시됨을 확인.
- **AC-2 (연령대·상태 말풍선 및 식탁 오브젝트 연동):** 연령대 스텝퍼(`10대`~`60대+`) 입력 시 캐릭터 상단 미니 태그로 표시되며, `SEATED`/`PAID`/`LEFT` 상태 전환이 도트 홀에 즉시 반영됨을 확인.
- **AC-3 (홀 배치 이동 모드):** `배치 이동 모드` 활성화 후 빈 마룻바닥 칸 터치 시 테이블 `(grid_x, grid_y)` 좌표가 즉시 변경·저장됨을 확인.
