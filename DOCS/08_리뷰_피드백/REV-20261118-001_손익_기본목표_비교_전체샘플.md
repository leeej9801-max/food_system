# 기본 목표·비교·전체 샘플 self-review

별도 리뷰어 없이 구현자가 수행한 **self-review**다. 최종 검사·이미지 확인 후 판정을 기록한다.

## 검토 및 수정
- 목표 필드별 null/0을 구분하며 기본값 변경은 기존 월 지정 값을 바꾸지 않는다. 기본 저장/월 저장의 감사 entity를 구분한다. 기존 PUT의 기본 동작 month는 유지한다.
- 날짜 없는 고정비를 포함한 월 이익과 날짜 실적만 쓰는 기존 전월 동기의 차이를 보존·설명했다. 새 주 비교는 월액을 달력 일수로 안분하고, 사용자가 선택한 비교의 원 금액을 별도 영역에 표시한다.
- 최초 주 비교의 자료 유무를 월 단위로 판정하면 같은 달 다른 주의 기록 때문에 빈 주를 0으로 오인할 수 있어, 날짜별 주문/입고 유무로 수정했다. 별도 월 수기 기록은 안분 가능한 근거로 인정한다. 자료 누락 평균은 null이다.
- 자동 카드수수료를 일별 반올림 비용에서 빼는 방식은 입고 소수 금액과 오차를 만들 수 있어 원 입고 금액을 직접 합하도록 수정했다. Decimal 계산, 반올림된 매출-지출=이익 일치를 확인한다.
- 목표 모달이 KPI grid 밖에 있으므로 grid 내부 색 변수에 fallback을 더했다. 범위 버튼 선택 표시, 해제 버튼·정수/금액 범위 검증·서버 오류를 제공한다.
- 샘플 교체는 매장+식별자로 제한하고 실제 기록을 보존한다. 입력된 월 비용 코드와 중복 생성하지 않는다. 샘플은 고정 난수, 실 POS/실명/비밀값 없음. 기존 최초 입고 삭제 조건은 공급처+notes 완전 일치다.

## 한계 및 후속 확인
- MINOR: 이 환경의 대량 샘플 INSERT/DELETE는 수 분 걸렸다. 별도 서버나 비동기 작업 시스템을 추가하지 않고 기존 동기 서비스로 유지했다. 반복 클릭은 UI pending으로 차단하지만 별도 클라이언트 동시 실행 부하는 미검증이다.
- MINOR: 주평균은 진행 주와 완료주 평균을 비교하므로 현재 주가 짧다. 숨기지 않고 툴팁·기준 기간에 표시했다. 월평균도 현재 월 진행분이라는 점을 명시한다. 계산 가정은 WO에 기록했다.
- 운영/실기기/실 POS/downgrade는 미검증. 근태 브랜치 0014/0015와 병합 시 migration 연결 정리가 필요하다.

## 최종 판정
목표 방식의 공유 변경(C-10)과 최종 검사 확인 대기. 현재 목표 코드는 WO의 기본 목표/월 덮어쓰기와 달라 완료 판정하지 않는다. 기존 구현을 임의 복원하지 않고 사용자에게 어느 계약을 유지할지 질문했다. 앞의 목표 검토 내용은 변경 전 구현 기준이며, 비교·seed 검사는 독립 일회용 DB/역할로 진행한다. 결과는 IR과 함께 갱신한다.
