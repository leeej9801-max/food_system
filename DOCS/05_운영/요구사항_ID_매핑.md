# 요구사항·화면 ID 매핑

> 통합기획서에 REQ 번호가 없어(C-09) §4.1 MVP P0 목록 순서대로 `REQ-001~013`을 부여한다. 원문 의미를 바꾸지 않으며, 원문은 [[음식점_AX_통합기획서_v1.0]]이 기준이다.
> 화면 ID는 UI 명세서의 `S00~S07`을 그대로 UI ID로 사용한다(별도 `UI-###` 미발급).
