### 2026-10-31 추가 확정 — U-14 (공개 데모)
지인에게 소개하는 프로토타입이므로 현재 `/food`에는 로그인/Cloudflare Access를 붙이지 않는다고 사용자가 명시했다. 무인증으로 같은 데모 데이터를 조회·수정할 수 있다는 설명 후의 승인이다. 이번 데모에 한해 P-05의 공개 전 인증 조건과 P-14의 Access 제안을 보류한다. 실제 운영/민감 데이터 사용 전 인증 도입은 후속 과제. 기존 LCI의 인증/서비스 설정은 변경하지 않는다. 출처: [[인터뷰_기록#6회차]], [[WO-20261031-001_Docker_및_food_경로_배포]].

### 2026-10-31 추가 확정 — U-15 (노트북 UI 밀도)
사용자는 과거 로컬 화면을 이미 축소해 봤을 수 있다고 정정하고, 현재 노트북에서 브라우저100%로67% 크기를 보도록 요청했다. 고정 화면비가 아닌 CSS viewport별 밀도로 구현: 너비1024~1535px·높이900px 이하·정밀 포인터에서67%, 모바일/터치전용/큰화면은 기존 크기. 기존 배포 버그의 원인이 확정됐다는 의미는 아니다. 출처: [[인터뷰_기록#7회차]], [[WO-20261031-002_로컬_배포_화면비율_진단]].
