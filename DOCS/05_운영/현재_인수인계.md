**환경 메모 (이번 세션에서 겪은 것)**
- 백엔드 venv는 `uv`로: `cd backend; uv sync --extra dev; uv run pytest`. (예전 `.venv\Scripts\*.exe` 경로 안내는 uv 이전 기준)
- 격리 테스트는 PostgreSQL 필요: 일회용 `postgres:17-alpine`을 `127.0.0.1:55432`로 띄우고 `RLS_TEST_DATABASE_URL=postgresql+psycopg://<owner>:<임시값>@127.0.0.1:55432/<db>` 설정 후 `uv run pytest tests/isolation`. 값은 문서에 남기지 않는다.
- Git Bash에서 `docker exec … /tmp/…` 경로가 Windows 경로로 바뀌므로 `MSYS_NO_PATHCONV=1`을 쓴다. `docker exec`로 stdin 스크립트를 넘길 땐 `-i`.
- 공개 URL 점검은 내장 브라우저로(파이썬 기본 User-Agent는 Cloudflare 1010 차단).
- Windows에서 파이썬으로 Vault 파일을 덮어쓸 때 `Errno 22`가 난 적이 있음(파일 잠금 추정) → 편집 도구로 재시도.
- `check-links.ps1`은 실행 정책 우회가 필요해 실행하지 않았고, 같은 규칙의 파이썬 검사로 깨진 링크 0건 확인.
