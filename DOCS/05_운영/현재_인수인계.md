## 3. 양식당 프로토타입 시연 순서 (End-to-End 워크플로)

1. 웹앱 접속 후 `S00` 2단계 위저드에서 매장명(예: `비스트로 서울`)과 초기 테이블 수(`6개`)를 생성합니다.
2. 좌측 메뉴 **설정 (S01/S07)** 화면으로 이동하여 우측 상단 **`✨ 양식당 프로토타입 마스터(식자재·메뉴·레시피·단가) 원클릭 세팅`** 버튼을 누르면 양식당 식자재 5종·메뉴 4종·레시피·초기 입고단가가 한 번에 준비됩니다 (가짜 매출은 주입되지 않음).
3. 같은 **설정 (S01)** 화면의 CSV 영역에서 **`양식당 샘플 CSV 불러오기` → `1단계: 미리보기 검증` → `2단계: 판매 데이터 확정 반영`**을 클릭하면 실제 판매 주문이 멱등 반영됩니다.
4. **홈 · 테이블 (S02)** 화면에서 테이블 카드를 터치해 방문 인원·연령대를 기록하고, **결제 완료(재석 유지)**와 **퇴점·테이블 비우기(이력 보존)**를 테스트합니다.
5. **입고·재고 (S05)** 화면에서 **실재고(실사 확인값)**와 **예상 재고(입고 - 판매×레시피 이론소모량 ± 폐기/조정)**가 분리되어 계산되는 것을 확인하고, 추가 입고/실사/폐기를 입력합니다.
6. **분석 대시보드 (S06)** 화면에서 메뉴별 원가·원가율·마진 및 **식자재 단가 변동 비파괴 시뮬레이션(`-5%`, `0%`, `+5%`, `+10%`, `+20%`)**과 시간대별·메뉴별 판매량 차트를 확인합니다.
